# John Young CV

This project contains a personal CV/resume website for John Young, built as a responsive static HTML page with a print-friendly layout.

## Overview

The site presents:
- A professional profile and contact details
- Core skills and technical competencies
- Work experience and project experience
- Education, certifications, and languages
- A modern, dark-themed layout optimized for both screen viewing and printing to PDF

## Project files

- `CV.html` — Main CV content and structure
- `CV.css` — Custom styling and print rules
- `images/` — Images used in the CV

## Running locally

Because this is a static site, you can view it directly in a browser:

1. Open `CV.html` in your browser, or
2. Serve the folder locally with a simple web server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Printing / exporting to PDF

Use the browser's print feature to save the page as PDF. The layout includes print media rules for A4 output.

## Notes

- The page uses Tailwind CSS via CDN.
- Font Awesome is used for icons.
- The design is tailored for a clean professional CV presentation.
